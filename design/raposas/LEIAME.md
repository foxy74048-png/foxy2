# Desenhos das raposas

Estilo escolhido em 2026-11-01: **Opção B — Arredondado amigável** (as outras opções, A geométrico e C emblema, ficam no gerador para referência).

Para ajustar cores ou acessórios: edite `gerar.php` e rode

```bash
php design/raposas/gerar.php /caminho/de/saida
```

e copie `saida/b/*.svg` para `public/core/assistants/`. Os sistemas recebem o endereço das imagens pela API (`avatar_url`), então trocar o arquivo não exige mudança em nenhum sistema.
